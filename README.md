# ERP System

Сучасна ERP-система для автоматизації бізнес-процесів малого та середнього бізнесу.

## 🌟 Основні можливості

- **Управління продажами**: обробка замовлень, робота з контрагентами.
- **Складський облік**: контроль залишків, номенклатури та складів.
- **AI Асистент**: інтелектуальна підтримка користувача за допомогою штучного інтелекту.
- **Мультикомпанійність**: підтримка декількох юридичних осіб в одній системі.
- **Звіти та аналітика**: візуалізація ключових показників бізнесу.
