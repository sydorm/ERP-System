# Antigravity Project Rules & Standards

Цей файл є обов'язковим для читання перед початком будь-якої роботи над кодом у цьому проекті.

## 1. Дизайн-система: Light SaaS 2026 (Nexora Style)

### Колірна палітра (Brand Palette)
*   **Primary Blue (Головний)**: `#1463FF` — основний бренд-колір для кнопок, активних станів та акцентів.
*   **Primary Indigo (Додатковий)**: `#6366f1` — для глибоких акцентів та альтернативних дій.
*   **Success Green**: `#15B97A` — статуси успіху, активні замовлення, оплати.
*   **Warning Amber**: `#F59E0B` — очікування, увага, попередження.
*   **Danger Red/Rose**: `#EF4444` — видалення, критичні помилки, скасування.

### Градієнти (Premium Gradients)
*   **Header/Primary Button**: `linear-gradient(135deg, #1463FF 0%, #0047D1 100%)`
*   **Success Button**: `linear-gradient(135deg, #15B97A 0%, #0E905F 100%)`
*   **Page Background**: `linear-gradient(135deg, #f8fafc 0%, #e2e8f0 100%)`

### UI Паттерни та Ефекти
*   **Glassmorphism (Скляний стиль)**:
    *   Фон: `rgba(255, 255, 255, 0.72)`
    *   Ефект: `backdrop-filter: blur(12px)`
    *   Бордер: `1px solid rgba(255, 255, 255, 0.4)`
*   **Тіні (Shadows)**:
    *   Card Soft: `0 4px 6px -1px rgba(0, 0, 0, 0.05)`
    *   Premium Hover: `0 10px 15px -3px rgba(15, 23, 42, 0.08)`
*   **Радіус (Border Radius)**:
    *   Контейнери/Картки: `16px`
    *   Кнопки/Інпути: `10px` — `12px`

### Типографіка
*   **Шрифт**: `Inter`, sans-serif.
*   **Кольори тексту**:
    *   Main: `#0F172A` (Slate 900)
    *   Muted: `#64748B` (Slate 500)
    *   Light: `#94A3B8` (Slate 400)
*   **Моноширинний**: `JetBrains Mono` (для артикулів та коду).

## 2. Архітектура коду (Frontend)
*   **Модульність**: Великі компоненти розбивати на дрібні (< 300 рядків).
*   **Стейт**: Використовувати Pinia для глобальних станів та `useDictionaryStore` для довідників.
*   **Компоненти**: Використовувати Element Plus як базу, але кастомізувати через CSS для преміального вигляду.
*   **Density**: Використовувати компактні Layout-и для ERP (Daily Use).

## 3. Робочий процес (Workflow)
*   **Git**: Після кожного завершеного завдання (фікса, рефакторинг, нова фіча) ОБОВ'ЯЗКОВО виконувати:
    ```powershell
    git add .
    git commit -m "опис змін"
    git push origin main
    ```
*   **Перевірка**: Перед комітом переконатися, що код не ламає існуючий UI та відповідає пропорціям ERP-системи.

## 4. Специфічні правила проекту
*   **Ніяких плейсхолдерів**: Використовувати реальні дані або AI-генерацію зображень.
*   **Тексти**: Тільки українською мовою в інтерфейсі (UA-локалізація).
*   **Чистота**: Прибирати зайві `console.log` та коментарі, що не несуть змісту.
