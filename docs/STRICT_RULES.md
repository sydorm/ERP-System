# Nexora ERP Design Standards

1.  **Grid System**:
    *   Container padding: `24px 32px`.
    *   Card gap: `24px`.
2.  **Layout Constants**:
    *   Sidebar width: `260px`.
    *   Top Navbar height: `64px`.
    *   Sticky elements must account for these offsets.
3.  **Modern SaaS Style (Vuexy Inspired)**:
    *   Primary color: `#6366F1` (Indigo).
    *   Success color: `#10B981` (Emerald).
    *   Page Background: `#F5F8FC` (Light Bluish-Grey).
    *   Standard border-radius: `12px` or `14px`.
    *   Card Background: `#FFFFFF`.
4.  **Button Standards**:
    *   Primary Action: `.btn-primary-modern` (or `.btn-primary-compact`).
    *   Secondary Action: `.btn-secondary-modern`.
5.  **Commit Policy**: Commits must be atomic and verified visually via Browser MCP.
