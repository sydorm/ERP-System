---
description: Як оновити код та сервер (Git + Vultr)
---

Цей воркфлоу описує кроки для безпечного оновлення системи.

> [!CAUTION]
> **ГЛОБАЛЬНЕ ПРАВИЛО:** Штучний інтелект (AI) **НЕ МАЄ ПРАВА** самостійно виконувати команди `git commit`, `git push` або запускати оновлення на сервері Vultr через термінал комп'ютера. 
> Після кожної значущої зміни коду, AI зобов'язаний **написати користувачу в чат готові команди** для копіювання, щоб користувач сам їх виконав.

1. **Відправка змін у GitHub (ВИКОНУЄ КОРИСТУВАЧ)**
   Напишіть користувачу цей блок коду:
   ```bash
   git add .
   git commit -m "Опис змін"
   git push origin main
   ```

2. **Оновлення сервера Vultr (ВИКОНУЄ КОРИСТУВАЧ)**
   Напишіть користувачу цей блок коду для терміналу Vultr:
   ```bash
   cd /var/www/ERP-System
   git pull origin main
   ./scripts/update.sh
   ```
   *(Примітка: якщо скрипт видає Permission Denied, користувач має виконати `chmod +x scripts/update.sh`)*

3. **Перевірка після оновлення**
   - Переконайтеся, що помилок немає.
   - Якщо виникають помилки міграцій Alembic (DuplicateTable, KeyError), фіксуйте їх в `error-handling.md`, щоб не повторювати.
