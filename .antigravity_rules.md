# Antigravity Project Rules & Standards

Цей файл є обов'язковим для читання перед початком будь-якої роботи над кодом у цьому проекті.

## 1. Дизайн-система: Light SaaS 2026 (Global Standard)

### Колірна палітра (Brand Colors)
*   **Primary (Основний)**: `#6366f1` (Indigo) — для головних кнопок, активних станів та акцентів.
*   **Secondary (Додатковий)**: `#8b5cf6` (Violet) — для вторинних акцентів та AI-функцій.
*   **Success (Успіх)**: `#10b981` (Emerald) — статуси "Активно", "Оплачено", позитивні сповіщення.
*   **Danger (Помилка)**: `#f43f5e` (Rose) — статуси "Скасовано", видалення, критичні помилки.
*   **Warning (Увага)**: `#f59e0b` (Amber) — очікування, попередження.
*   **Neutral (Текст та фони)**:
    *   Main Text: `#0f172a` (Slate 900)
    *   Muted Text: `#64748b` (Slate 500)
    *   Border: `#e2e8f0` (Slate 200)
    *   App Background: `#f1f5f9` (Slate 100)
    *   Card Background: `#ffffff` (White)

### UI Паттерни
*   **Стилістика**: Glassmorphism (скляні ефекти).
    *   `backdrop-filter: blur(20px) saturate(180%)`
    *   `background: rgba(255, 255, 255, 0.7)`
*   **Тіні (Shadows)**:
    *   Soft: `0 1px 2px rgba(15, 23, 42, 0.05)`
    *   Premium: `0 4px 12px rgba(15, 23, 42, 0.08)`
*   **Радіус (Border Radius)**:
    *   Cards/Inputs: `12px`
    *   Buttons: `8px` — `10px`
    *   Badges: `6px`

### Типографіка
*   **Шрифт**: `Inter` або `Outfit` (якщо доступно), системний `Sans-serif` як запасний.
*   **Розміри**:
    *   H1/H2: `18px` — `22px` (Bold 800)
    *   Body: `13px` — `14px`
    *   Small/Muted: `11px` — `12px`
*   **Код/Артикули**: `JetBrains Mono` або `Monospace`.

## 2. Архітектура коду (Frontend)
*   **Модульність**: Великі компоненти розбивати на дрібні (< 300 рядків).
*   **Стейт**: Використовувати Pinia для глобальних станів та `useDictionaryStore` для довідників.
*   **Компоненти**: Використовувати Element Plus як базу, але кастомізувати через CSS для преміального вигляду.
*   **Density**: Використовувати компактні Layout-и для ERP (Daily Use).

## 3. Робочий процес (Workflow)
*   **Git**: Після кожного завершеного завдання (фікса, рефакторинг, нова фіча) ОБОВ'ЯЗКОВО виконувати:
    ```powershell
    git add .
    git commit -m "опис змін"
    git push origin main
    ```
*   **Перевірка**: Перед комітом переконатися, що код не ламає існуючий UI та відповідає пропорціям ERP-системи.

## 4. Специфічні правила проекту
*   **Ніяких плейсхолдерів**: Використовувати реальні дані або AI-генерацію зображень.
*   **Тексти**: Тільки українською мовою в інтерфейсі (UA-локалізація).
*   **Чистота**: Прибирати зайві `console.log` та коментарі, що не несуть змісту.
